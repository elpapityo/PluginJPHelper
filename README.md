# Plugin JP Helper v0.4.12
## v0.4.12 テスト項目

- Plugin Installerを開いた直後、`Loading repositories...` 中は説明翻訳を開始しません。
- `PluginsReady` と `ReposReady` の両方を確認後、さらに2.5秒待ってからInstaller専用翻訳を開始します。
- 読み込み中にPJHがManifestを書き換えないことを最優先にしたテスト版です。
- 通常プラグイン辞書は引き続きPlugin Installerへ流しません。


## v0.4.12 主な変更
- 辞書更新・再読み込みと画面描画が重なった際に `config.Plugins` の列挙で例外になる可能性があった処理を修正
- 通常プラグイン用の翻訳辞書（公式／ユーザー／コミュニティ）をDalamud Plugin Installer内では使用しないよう分離
- Plugin Installer専用の説明・詳細・更新履歴翻訳は従来どおり専用処理で動作
- Dalamud Plugin Installer のプラグイン説明・詳細説明を日本語化
- 日本語検索補助
- Remote Manifest のみを差分検出・Google翻訳の対象にし、Local-only/private は送信しない
- インストール済み公開プラグインには表示用翻訳を適用
- Google 429 / HTTP / 接続 / タイムアウト等を明確表示
- 更新プラグイン一覧と詳細ログ
- FFXIV用語GlossaryをGoogle送信前に保護して公式・定着用語を優先
- 翻訳JSONは「翻訳ファイルを選択」から別名ファイルも選択可能

開発者：**Elpa**

Dalamudプラグインの表示文字列を、日本語CSV辞書で日本語表示する補助プラグインです。

## 特徴

- タイトルバーのハートボタンからOFUSE支援ページを開けます。

- 翻訳対象プラグイン側のコード・設定・内部IDには手を加えません。
- `##ID` / `###ID` などのImGui内部IDを保持し、表示文字列だけを日本語化します。
- Plugin JP HelperをOFFにすると翻訳処理は停止し、対象プラグインは元の表示へ戻ります。
- ローカル辞書、公式辞書、コミュニティ辞書を用途に応じて利用できます。
- UIは日本語表示を基本とし、プラグイン名・コマンド・InternalName・CSV列名など技術上必要な項目だけ原文を保持します。

## 主な機能・改善

- 公式辞書／コミュニティ辞書に「対応プラグイン」を表示。
- 必要に応じて次の状態列を表示できます。
  - 翻訳辞書登録：有り / 無し
  - 未翻訳登録：有り / 無し
  - 日本語化：ON / OFF
  - 導入：導入済み / 未導入
  - プラグインスイッチ：ON / OFF
- 「最小表示」「全部表示」で詳細列を一括切替できます。
- BossMod / RSRなど、略称・InternalName・旧登録名が混在する場合も一致する設定を集約して状態判定します。
- RSR / RotationSolverReborn、BMR / BossModReborn、BM / BossMod を明示的な別名として扱います。
- 「インストール済みプラグインから追加」では、すでに登録済みのプラグインを候補から除外します。
- 公式辞書・コミュニティ辞書・翻訳辞書・未翻訳一覧のテーブルを横スクロール型へ統一しました。列を広げても他列を押し縮めません。
- 公式辞書・コミュニティ辞書・未翻訳一覧に並び順／昇順・降順を追加しました。翻訳辞書の既存ソートも維持します。
- Artisanの `List Editor` / `Processing List` と可変表示の翻訳対応を維持しています。
- ローカルテストとして、MarketBoardPlugin / GatherBuddyReborn / Artisanがゲーム内ContextMenuへ追加する一部項目の日本語化に対応しています。

詳細は `CHANGELOG.md` を参照してください。

## 基本的な使い方

1. Plugin JP Helperをインストールして有効にします。
2. `/pjph` で設定画面を開きます。
3. 「未翻訳・取得」タブの「インストール済みプラグインから追加」から対象プラグインを追加します。
4. 「翻訳辞書」タブで対象プラグインを選びます。
5. CSV辞書を使う場合は「CSVを選択して読み込む」から読み込みます。
6. 対象プラグインの日本語化を有効にします。

CSVの基本形式：

```text
Plugin,Menu,Section,Type,English,Japanese
```

## 公式辞書

- 「公式辞書一覧を取得」でGitHub上の公式辞書一覧を確認できます。
- 必要な辞書だけ選択してダウンロード／更新できます。
- 公式辞書の追加・更新・削除があるとタイトルバーへ通知します。
- 更新確認は起動時と、その後1時間ごとに行います。

## コミュニティ辞書

- 「コミュニティ辞書一覧を取得」で公開中の辞書を確認できます。
- 必要な辞書だけ選択してダウンロード／更新できます。
- 「コミュニティ辞書をアップロード」からGitHubアカウントなしでWeb投稿できます。
- 投稿時に設定した削除用パスワードで、自分の投稿をWebから削除できます。

## 公開前の注意

コミュニティ辞書CSVには、対象プラグインによってキャラクター名・サーバー名・FC名・ログ・座標・時刻などが含まれる可能性があります。投稿前にCSVを確認し、個人的・動的な情報を削除してください。

## 未翻訳取得の自動翻訳（v0.4.3）

未翻訳取得後に、翻訳可能な固定UI文字列だけをGoogle翻訳で下書きできます。FF14用語、プラグイン名、URL、コマンド、ImGui IDなどは翻訳前に保護します。作者・クレジット、パス、動的値、技術IDなどは対象外です。結果は自動保存せず、確認後に辞書へ反映してください。

自動翻訳ログでは、翻訳結果・保護・スキップ理由・Google側エラーを確認できます。その他取得分は「対象候補 / 他プラグイン / 判定不能」に分け、対象候補だけ確認後に対象プラグインへ移せます。


### 未翻訳取得と自動翻訳
「未翻訳・取得」内は「未翻訳取得」と「自動翻訳」に分かれています。取得中・自動翻訳中・翻訳結果確認待ち中は、誤操作防止のため対象変更や関連ボタンが一時的に無効になります。自動翻訳はGoogle翻訳を利用した下書き補助で、既存のユーザー訳・公式訳は自動上書きしません。詳しい手順はゲーム内の「ヘルプ」タブを確認してください。
