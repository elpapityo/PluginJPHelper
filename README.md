# Plugin JP Helper v0.3.1

開発者：**Elpa**

Dalamudプラグインの表示文字列を、日本語CSV辞書で日本語表示する補助プラグインです。

## 特徴

- 翻訳対象プラグイン側のコード・設定・内部IDには手を加えません。
- `##ID` などのImGui内部IDは変更せず、表示文字列だけを日本語化します。
- Plugin JP HelperをOFFにすると、翻訳処理は停止し対象プラグインの表示は元に戻ります。
- 通常は設定画面を開いたままにする必要はありません。
- ローカル辞書、公式辞書、コミュニティ辞書を用途に応じて利用できます。

## v0.3.1 の主な変更点

- Artisanの製作リスト画面（`List Editor` / `Processing List`）をArtisan所属として正しく認識するよう修正しました。
- 既にArtisanを翻訳対象へ登録している環境でも、必要なウィンドウ判定キーワードを起動時に自動補完します。
- Artisanの製作リストで、時間・進捗・品質・製作中アイテムなど値が毎回変わる表示をPJH本体側で安全に翻訳するよう対応しました。
- `Craft completed with full quality in 6s!` のように秒数が変化する完了表示にも対応しました。
- `Retainer Item: ...` は固定部分だけ翻訳し、アイテム名・個数など後続の可変情報をそのまま保持します。
- 動的翻訳では数値・アイテム名を保持し、`##` / `###` のImGui内部IDは変更しません。
- Artisan専用処理として実装しており、他プラグインへ汎用部分一致を広げる変更は行っていません。

詳細は [CHANGELOG.md](CHANGELOG.md) を参照してください。

## 基本的な使い方

1. Plugin JP Helperをインストールして有効にします。
2. 必要なときだけ `/pjph` で設定画面を開きます。
3. 「未翻訳・取得」タブの「インストール済みプラグインから追加」から、日本語化したいプラグインを追加します。
4. 「翻訳辞書」タブで対象プラグインを選びます。
5. CSV辞書を使う場合は「CSVを選択して読み込む」から読み込みます。
6. 対象プラグインの日本語化を有効にします。

CSVの基本形式：

```text
Plugin,Menu,Section,Type,English,Japanese
```

## 未翻訳文字列を取得する場合

1. 「未翻訳・取得」で対象プラグインを選びます。
2. 「取得開始」を押します。
3. 対象プラグインの画面・メニュー・ツールチップなどを操作します。
4. 取り込み方式は通常「自動」で使用できます。不要項目を整理したい場合は「手動」に切り替えます。
5. 手動時は取得一覧の「削除」または検索後の「検索結果を削除」で不要項目を除外できます。
6. 「取得停止」を押します。
7. 手動時は「翻訳辞書へ取り込む」を押し、残した項目だけを辞書へ取り込みます。

## 公式辞書

- 「公式辞書一覧を取得」でGitHub上の公式辞書一覧を確認できます。
- 必要な辞書だけ選択してダウンロード／更新できます。
- 公式辞書の追加・更新・削除があるとタイトルバーに通知します。
- 更新確認は起動時と、その後1時間ごとに行います。

## コミュニティ辞書

- 「コミュニティ辞書一覧を取得」で公開されているコミュニティ辞書を確認できます。
- 必要な辞書だけ選択してダウンロード／更新できます。
- 「コミュニティ辞書をアップロード」から、GitHubアカウントを使わずWeb投稿できます。
- 「自分の投稿名」にWeb投稿時と同じ投稿者名を設定すると、自分の投稿を `[自分]` として確認できます。
- 投稿時に設定した削除用パスワードで、自分が投稿した辞書をWebから削除できます。

### コミュニティ辞書を投稿する前の注意

プラグインによっては、キャラクター名・サーバー名・FC名など、個人を特定される可能性がある表示文字列まで取得され、CSVに含まれる場合があります。

投稿前にCSVを開き、**自分のキャラクター名やサーバー名などで検索してください**。該当する行が見つかった場合は、その行を削除してからアップロードしてください。

必要に応じて、他のキャラクター名、ログ、座標、時刻などの個人的・動的な情報も確認してください。Plugin JP Helperですべての個人情報を自動判定することはできないため、公開前の最終確認は投稿者自身で行ってください。

## 更新通知

PJH起動時と、その後1時間ごとに公式辞書・コミュニティ辞書の更新を確認します。

更新がある場合はタイトルバーに次のように表示されます。

```text
Plugin JP Helper v0.3.1 【公式辞書に更新があります。】【コミュニティ辞書に更新があります。】
```

## 注意

表示方法によっては、一部の文字列やツールチップに翻訳が適用されない場合があります。

動作が不安定になった場合は、まずPlugin JP HelperをOFFにしてください。OFFにすると翻訳処理は停止し、対象プラグインは元の表示に戻ります。

## ビルド

Windowsで `build.bat` を実行してください。

成功すると以下を作成します。

```text
release\PluginJPHelper\
release\PluginJPHelper_v0.3.1.zip
```

`PluginJPHelper_v0.3.1.zip` はGitHub Releaseへ添付するDalamud配布用ZIPです。
