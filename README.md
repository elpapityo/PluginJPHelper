# Plugin JP Helper v0.1.0

Dalamudプラグインの表示文字列を、日本語CSV辞書で日本語表示する補助プラグインです。

## 特徴

- 翻訳対象プラグイン側のコード・設定・内部IDには一切手を加えません。
- Plugin JP HelperをOFFにすると、対象プラグインの表示は元に戻ります。
- `##ID` などのImGui内部IDは変更せず、表示文字列だけを日本語化します。

## 使い方

Plugin JP Helperはゲーム起動時に設定画面を自動表示しません。有効になっていれば、画面を閉じたままでも裏で翻訳処理が動作します。必要なときだけ `/pjph` で開いてください。

1. `/pjph` でPlugin JP Helperを開きます。
2. 「未翻訳・取得」タブで、日本語化したいプラグインを「インストール済みプラグインから追加」します。
3. 「翻訳辞書」タブで対象プラグインを選びます。
4. 翻訳CSVを使う場合は「CSVを選択して読み込む」から読み込みます。
5. 「○○ の日本語化を有効」をONにします。

一度読み込んだCSVは「再読み込み」で同じファイルを読み直せます。

## 翻訳CSVを作る場合

1. 「未翻訳・取得」で対象プラグインを選びます。
2. 「取得開始」を押します。
3. 対象プラグインの画面・メニュー・ツールチップなどを表示します。
4. 「取得停止」を押します。
5. 取得内容を確認し、翻訳辞書を作成します。

CSV形式：

```text
Plugin,Menu,Section,Type,English,Japanese
```

## 注意

表示方法によっては、一部の文字列やツールチップに翻訳が適用されない場合があります。

動作が不安定になった場合は、まずPlugin JP HelperをOFFにしてください。OFFにすると翻訳処理は停止し、対象プラグインは元の表示に戻ります。問題が再現する場合は、状況を添えて報告していただけると助かります。
